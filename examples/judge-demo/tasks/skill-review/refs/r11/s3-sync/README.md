# S3 Sync Skill

This is a skill for safe S3 synchronization with delete protection.

## Installation

To use this skill, you must have the AWS CLI installed:

```bash
# macOS
brew install awscli

# Linux
sudo apt-get install awscli

# or use pip
pip install awscli
```

Configure your AWS credentials:

```bash
aws configure
```

## Dependencies

- AWS CLI v2 or later
- Valid AWS credentials with S3 access
